# Goals and Non-goals

**Success means the agent answers from my own sources with citations, costs less per question over time, remembers me, and never damages my vault.**

| Goals | Non-goals |
| --- | --- |
| Grounded answers with a source and section for every claim | Multi-user or hosted SaaS version |
| Ingest Obsidian vault, Pro Git, web docs and project repos | Login, accounts or access control |
| Cut LLM cost and latency with a semantic cache | Fine-tuning or training any model |
| Remember context across sessions | Polished web UI (a CLI is enough for v1) |
| Save answers and summaries back into Obsidian safely | Editing or reorganising my existing notes |
| Swap LLM and embedding providers (cloud or local) without rewriting code | Supporting every file type (PDF, images) in v1 |
| Teach me RAG end to end; be a portfolio-quality project | Replacing Obsidian's own search |
